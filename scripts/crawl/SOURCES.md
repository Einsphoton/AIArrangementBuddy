# 可爬性核查（2026-11 实测）

> 只记录**实测结果**，不猜。核查方法：请求 `/robots.txt` + 抓一个真实页面看下载链接结构。
> 结论会随站点政策变化，重跑核查前请先复核。

## 一、结论总表

| 站点 | robots.txt | 页面结构 | 能直接爬吗 | 说明 |
| --- | --- | --- | --- | --- |
| **vgmusic.com** | 404（未设置） | 目录页直接列 `<a href="xxx.mid">` | ✅ **可以** | 通用适配器直接可用；SNES 6,708 / NES 4,204 / 全站 3 万+ |
| **bitmidi.com** | `Disallow: /uploads/` | 歌曲页的下载链接**正好在 `/uploads/`** | ⛔ **文件下载被禁** | 页面可抓（113,229 条的元数据），文件不行。想批量拿文件需**联系站方授权** |
| **midishrine.com** | `Disallow: /` | — | ⛔ **明确禁止全站** | 不要爬 |
| **songsterr.com** | 403（直接拒绝机器人） | 无文件下载，只有在线播放 | ⛔ **禁止且无文件** | 不要爬 |
| **ultimate-guitar.com** | 部分路径允许，但 ToS 禁止抓取 | 下载 `.gp3/.gp4/.gp5/.gpx` 需登录 | ⛔ **不爬** | 改走「你自己下载 GP 文件 → 本地转换」，见 `convert-gp.mjs` |
| **ichigos.com** | 允许（仅禁 forum） | 以**乐谱（PDF）**为主，MIDI 零散 | ⚠️ 需逐页确认 | 通用适配器可能抓不到多少 |
| **freemidi.org** | `Allow: /` | 歌曲页**没有直链 `.mid`**，下载走参数化端点 | ⚠️ 需专用适配器 | 有量，但要针对它写适配器 |
| **kunstderfuge.com** | 仅禁 `/_` | 古典 MIDI，按作曲家分页 | ⚠️ 需专用适配器 | 古典（公有领域）为主 |
| **free-scores.com** | 大部分允许 | 乐谱站，MIDI 零散 | ⚠️ 需专用适配器 | — |
| **gprotab.net** | 301 跳转，需复核 | Guitar Pro 文件，`?download` 可直下 | ⚠️ 待复核 | 转换后可用（已用真实 `.gpx` 验证） |

**一句话**：你给的四个线索里，只有 **VGMusic 能直接爬**；MidiShrine 明确禁止、Songsterr 直接拒绝机器人、Ultimate Guitar 是 ToS + 登录墙 + 非 MIDI 格式。这不是"技术做不到"，是"不该这么做"。

## 二、那 11 万条从哪来？

BitMidi 有 **113,229** 条 MIDI 元数据（页面可抓），但文件在 `robots.txt` 明确禁止的 `/uploads/` 下。
可选的三条路：

1. **联系站方**（最干净）：BitMidi 是志愿者维护的小站，写邮件说明「本地研究用途、只取元数据+少量样本、不转载」，很多小站会同意。
2. **只抓元数据**：曲名/艺人/页面对我们其实价值有限（我们缺的是音符），性价比不高。
3. **放弃**：转去 GigaMIDI（数据量是它的 20 倍）。

## 三、GigaMIDI 的真实门槛（纠正我之前的说法）

- 规模：**210 万**个 MIDI（v2.0.0 扩展版，含 loop 标注）
- 位置：Hugging Face `Metacreation/GigaMIDI`
- **需要申请访问**（gated dataset），不是直接下载
- 数据量级：百万级 MIDI，磁盘预计数百 GB；建议先只取元数据/标注，按标签筛完再下对应分片

所以「一个下午搞定几十万」不成立 —— 先申请，审批通过后再按需分片下载。**申请应该今天就开始，因为它不阻塞别的活。**

## 四、合法的替代来源（无需爬虫）

| 来源 | 用途 |
| --- | --- |
| GigaMIDI（申请后） | 210 万，四类风格的唯一大规模来源 |
| MetaMIDI / Lakh（HF/GitHub 直接下） | 44 万 / 17.6 万，弱标签 |
| NES-MDB、VGMIDI（GitHub） | JRPG 早期曲目、动机与和声 |
| Slakh2100、MAESTRO、GMD | 配器结构、演奏层 |
| **你自己的 Guitar Pro 收藏** | 用 `convert-gp.mjs` 转成 MIDI（已用真实 `.gpx` 验证） |
| 你已有的 MIDI 收藏 / 购买的正版 MIDI 包 | 直接放进 `data/corpus/<style>/<source>/` |
