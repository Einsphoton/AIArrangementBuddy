## 2. 关键发现与修复

### 2.1 Textfield / 表单（用户明确反馈）

1. **多行输入被全局 `.field` 的固定高度压扁**（P0）
   - 现象：`textarea` 带 `className="field"` 时被 `.field { height: 32px }` 强制成单行，`rows={3}` 的「音频描述」实际只有 32px，只能看到一行。
   - 修复：`styles/index.css` 增加 `textarea.field { height:auto; min-height:72px; padding:8px 10px; line-height:1.6 }`，单行/两行 textarea 例外。
   - 影响：高级生成面板、局部重绘、工程菜单里的多行输入全部恢复正常行高。

2. **右侧 AI 输入框太矮、留白/填充感差**（P0）
   - 现象：AI 面板输入框只有 40px 高、单行观感，像搜索框；下方还有一条重复状态行挤压空间。
   - 修复：输入区重做 —— 最小 88px（约 3 行）、随内容自动增高至 240px；把「命令 / Enter 提示 / 发送/停止」收进输入框底部工具条；移除重复的底部状态行；模型/服务商状态改为面板头部可点击入口。
   - 结果：1440 宽度实测输入框 90px 高、宽度 369px / 容器 371px（撑满）。

3. 其余表单问题（各界面按范围修复，详见各修复清单）：原生白底 `.input` 与设计系统不一致、主按钮缺强调色、数字/小数秒输入被 `Number` 归一化后不可用、长文案与标签截断、1280×800 下弹窗底部按钮不可达等。

### 2.2 音频生成入口与意图（用户明确反馈）

原来：顶栏一个孤立的「生成音频」弹窗，用户要先想清楚「我要 MIDI 还是音频」，再去表单里填英文 caption、BPM、时长、适配器、质量模式、分轨 —— 入口与 AI 编曲助手割裂。

现在：**音频能力收进 AI 编曲助手，由自然语言意图驱动**。

- 顶栏移除：生成音频 / 生成节点在线 / 安装本机引擎 / 训练风格 / 任务中心等 5 个入口（顶栏只保留 文件、撤销重做、工程名、命令搜索、新建、保存、AI 助手、AI 就绪）。
- AI 面板右上新增「音频引擎」按钮：状态灯 + 菜单（生成节点状态、复制启动命令、安装本机引擎、高级参数、任务中心、训练风格）。
- 聊天快捷动作新增：生成整首音频 / MIDI → 音频 / 生成分轨；Slash 命令新增 `/audio`、`/render`、`/stems`；空状态示例新增「直接生成一首音频」。
- 用户只说一句话，AI 判断模式：
  | 用户意图 | 模式 | 执行 |
  | --- | --- | --- |
  | 从零要成品音频 / 没有可用 MIDI | `text_to_audio` | Companion 文本生成整首音频 → 自动落一条音频轨 |
  | 已有编曲，要「导出 / 渲染 / 听成品」 | `midi_to_audio` | 浏览器离线渲染当前工程（含每轨链/母线/主音量）→ 上传资产 → 落音频轨 |
  | 要「先编曲再出音频」 | 先 MIDI 工具编曲，再 `midi_to_audio`（或 `midi_then_audio`） | 先写 MIDI，再渲染 |
  | 要「分轨 / 分开乐器」 | `audio_with_stems` | 先生成整曲，再按 guitar/bass/drums/... 逐条生成 stem，各自成轨 |
- 实现分层：
  - 服务端工具 `apps/server/src/tools/audio.ts#generate_audio`：**只决定做什么**，校验并返回 `data.audioPlan`（不执行长任务）。
  - 内置 Agent 的 `tool_end` 携带 `data`；前端 `useChatStream` 收到后交给 `features/audio/audioIntent.ts` 异步执行。
  - 执行进度进入 AI 面板内的「音频任务卡」（步骤、进度、取消、失败原因、下一步动作）。
  - Codex / DSH 等外部 Agent 的 `tool_end` 不带 data：同一轮对话结束后按用户原话做保守的启发式兜底，避免「只说不做」。
- **缺少本机模型时自动弹下载对话框**（用户补充要求）：
  - 音频任务提交前检查 Companion 与 `/api/provision/status`；
  - 未安装运行时/模型 → 自动打开「安装本机 AI 引擎」对话框，展示原因（"AI 想生成音频，但本机缺少生成环境"）、自动勾选所需能力（分轨模式额外勾选 stems），用户确认后开始下载；
  - 模型已安装但生成节点未启动 → 提示并给出可复制的 Companion 启动命令，不伪造成功。

### 2.3 其他 UI / 交互修复（并行修复单元）

#### 设置 / 导出 / 帮助 / 命令面板 / AI 音频弹窗

真实 bug 优先：

1. **模型选择器按 Esc 会连带关闭整个设置弹窗**；弹层在页面滚动后定位到视口外点不到 → Esc `stopPropagation` 只关下拉；打开时先 `scrollIntoView` 再按上下可用空间限高定位。
2. **设置里有未保存修改时按 Esc 会静默丢弃草稿** → 捕获阶段接管 Esc：脏状态只弹「放弃修改 / 继续编辑」，不再直接关闭；去掉 footer 重复按钮。
3. **局部重绘的「秒」输入框无法输入小数**（受控 Number 把 "0." 归一成 0）→ 文本 state + `sanitizeDecimal`，实测 0.5 / 2.5 正常。
4. **训练面板使用不存在的 `.input` / `btn-primary` 类**（原生白底控件、主按钮灰色）且训练中无法关闭 → 统一 `.field` / `btn-accent`、补 Esc、面板内部滚动 + 固定底部操作区。
5. Modal 补 `aria-labelledby` / 初始焦点 / 焦点还原 / Tab 循环；Toast z-index 70→300（不再被 Companion 面板盖住）；Welcome 的 Esc 现在会写入已读标记。
6. 任务中心「关闭」误用旋转 Play 图标；旧服务端缺 `summary` 字段会白屏 → 图标修正 + 可选链兜底。

信息架构与密度：

- `GenerateAudioPanel` 收敛为「状态条 + 描述 + BPM/时长/风格 + 提交」主路径；优先级 / 适配器 / 质量模式 / AI 重编收进「高级参数」，一键整曲 + 分轨单独折叠；保留全部 `data-*` 自动化钩子。
- Repaint / Stem / 设置各 tab / Export / Help / CommandPalette / 右键菜单的 9–10px 文案统一提到 10.5–11.5；1280×800 下无裁切、按钮可达。
- Export 新增「将导出为 xxx.mid（无需填写后缀）」预览并去重后缀；格式卡补 radio 语义；后端不可达提示去掉硬编码端口。

#### 编曲 / 轨道 / 钢琴卷帘 / 智能片段 / 走带 / 混音器 / 文件菜单

真实 bug 优先：

1. **文件菜单 →「新建工程…」的向导点第一下就消失**：向导 portal 到 body 后，菜单的「点外面关闭」把它连带卸载 → 弹层打开时不再注册菜单外点关闭（简谱弹层同样修复并补 Esc）。
2. **「新建工程」入口不一致**：命令面板命令改派发 `aiab:open-new-project-wizard`；新增可复用 `NewProjectWizardDialog`（Esc / 遮罩 / 未保存提示），顶栏、命令面板、文件菜单三处同一组件。
3. **混音器拖到最矮时 dB 标尺标签互相压住** → 按推子高度自适应抽稀刻度，实测 0 重叠；混音器最小高度按 chrome + 最小推子钳制（200→235px），不再裁掉通道条底部。
4. **混音器 1280/1440 下通道条固定 78px，右侧大片空白** → 弹性 88–144px 铺满；推子 / M/S / REV/DLY / 主输出同步放大。
5. Textfield：轨道重命名 17→22px、循环小节 26×18→40×26、智能片段「补全进行」24px→28px、乐器搜索 18→30px；并修了 1120 宽智能片段参数被压成单列的问题。
6. 连带的密度/可读性：轨道头 R/M/S/试听 16→18px、片段徽标 8.5→9.5px、编曲标尺 8→9.5px、钢琴卷帘下拉 28→30px、状态栏可点项统一 19px、AI 混音弹窗字号与勾选框放大。
7. 真实交互回归：双击改名 + ⌘Z、右键菜单视口内 + Esc、片段拖动 + 撤销、框选 10 片段、双击空白建片段、Space/L/M/F、切片工具、混音器推子/静音、24 轨横向滚动、两个向导入口、乐器弹层搜索、颜色弹层、AI 混音弹窗 Esc 全部通过；控制台 0 错误。

量化结果（1440 / 1280 / 1120）：<9.5px 文本 205→0；文本控件过矮/过窄/字太小/值截断 0；固定工具条子元素越界 0；轨道头溢出 0；dB 标尺标签重叠 9→0。

## 4. 已知边界

- 生成本机音频仍需 Companion 运行（模型下载完成后不会自动常驻启动）；菜单里提供启动命令复制。
- 文本→音频依赖 ACE-Step 模型与英文 caption；中文描述由 Agent 翻译提炼，外部 Agent 兜底时可能质量下降，建议使用内置 Agent 或高级面板。
- 离线渲染在某些无 AudioWorklet 的浏览器会回退到内置合成器（`[render] SoundFont 单轨渲染失败，回退合成器` 属既有降级路径），渲染结果仍可用但音色可能与试听略有差异。
- 外部 Agent 后端（Codex / DSH）拿不到工具 data，音频兜底为启发式计划，参数精度低于内置 Agent。
- `store.clearSelection()` 只清音符不清片段（App Esc 用）：钢琴卷帘「未选中片段」空态正常，但 Esc 无法从钢琴卷帘退到空态；属既有语义，本轮未改。
- 原生 `input[type=range]` 的视觉高度统一涉及全局滑杆样式，本轮只保证可拖拽与可读，未统一到 24px 触达高度。
- Modal 已补 Tab 焦点循环＋初始焦点＋关闭还原；portal 到 body 的下拉（如模型选择器）不在该循环内，复杂嵌套焦点管理仍是后续项。
