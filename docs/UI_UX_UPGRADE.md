## 3. 设计原则（本次施工遵循）

1. **一处定义，多处复用**：命令、快捷键、菜单文案只在 `lib/commands.ts` 定义，命令面板/帮助/工具栏共用。
2. **直接操作优先，修饰键做加速**：点击空白时间轴=定位播放头；`⌘/Ctrl` 拖拽=复制；`Alt` 拖拽=临时切片（后续）；`Shift`=加选。
3. **状态永远可见**：录入、跟随、吸附、工具、保存状态在工具栏/状态栏有明确指示，不只存在于设置里。
4. **就地右键**：时间轴、片段、轨道头、音符、混音通道都提供右键菜单，避免「去别处找按钮」。
5. **可发现性**：每个非显然操作都有 tooltip + 快捷键角标；`⌘K` 可搜索全部命令。
6. **渐进披露**：轨道头放高频控件；低频设置进右键/检查器；面板可折叠。
7. **安全**：一切编辑进撤销栈；破坏性操作有确认或可撤销；AI 改动始终可一键回退。
8. **不假装**：做不到的能力（如音频录音、自动化）不放进 UI；对 MIDI 录入等能力文案保持诚实。

### 6.3 关键交互决策

1. **命令层与执行层分离**：命令面板/帮助/快捷键只是「意图」，缩放、拆分、量化等视图动作经 `editorBus` 由当前视图执行，避免三套逻辑漂移。
2. **不抢视图的键**：全局只接管跨视图命令键（⌘K / ⌘J / F / R / ⌘⇧M / ⌘, / ⌘⇧E / ⌘⇧N / ⌘0 / ⌘= / ⌘- / ⌘D / ⌘E）；Delete、⌘A、⌘C/V、Q、方向键归当前视图，避免同一按键触发两次。
3. **悬浮层统一**：右键菜单用 portal + 视口夹取 + 点击外部/Esc/滚轮关闭，样式与键盘可读性统一。
4. **面板可调整**：AI 面板宽度、混音器高度、轨道行高都进 `uiStore` 并持久化；关闭/重开浏览器仍保留工作区形态。
5. **真实反馈**：混音器与轨道头电平来自引擎 per-track meter（合成器与采样音源两条路由都覆盖），不再用 master 电平估算。
6. **渐进披露**：钢琴卷帘把低频操作收进「更多」菜单，保证 AI 面板打开时的 1024px 编辑区也不出现截断。
7. **安全**：批量拖动/行高/A-B 等交互保持「一次手势一个撤销点」；AI 改动仍可整轮撤销；首次引导在自动化环境（`navigator.webdriver`）自动跳过。

## 7. 第二轮：窄屏布局鲁棒性（用户反馈「文字被裁 / 遮挡」）

### 7.1 根因（不止一处）

1. **全局 CSS 未分层覆盖**：`styles/index.css` 里有一条未分层的
   `input, select, textarea, button { font: inherit; }`。CSS Cascade Layers 规则下，
   **未分层普通声明优先于 `@layer utilities`**，于是所有按钮/下拉/输入框的 `text-[10.5px]` 等
   Tailwind 字号都被强制回 16px —— 走带、工具条、轨道头、混音器的内容因此普遍比设计宽 30–50%，
   在 1440/1280/1120 下溢出被父容器裁掉。修复：删除这条重复规则（表单继承交给 Tailwind preflight 的 `@layer base`）。
2. **容器缺少可伸缩约束**：若干工具条/轨道头没有 `min-w-0` / `shrink-0` / 响应式隐藏，内容一多就压出边界。
3. **用 `no-scrollbar` 掩盖溢出**：走带、混音器通道、钢琴卷帘工具条在窄屏时横向溢出且隐藏滚动条，
   用户既看不到也滚不到被裁掉的控件。
4. **弹窗/窄面板缺少边界处理**：AI 面板宽度被压到 300–360px、混音器仍按固定高度展示等。

### 7.2 新增：自动化布局审计

`scripts/audit-layout.mjs`（`pnpm audit:ui`）：真实 Chrome + CDP，在 **1024 / 1120 / 1280 / 1440 / 1680**
五个宽度 × 11 个界面状态（编曲、宽编曲、钢琴卷帘、智能片段、混音器、帮助、设置、导出、命令面板、引导、窄条 AI 面板）
下自动检测：

| 检测项 | 含义 |
| --- | --- |
| `clip-x / clip-y` | 元素自身文字被 `overflow:hidden` 裁剪 |
| `clipped-by-parent` | 被祖先容器裁掉（可滚动容器不算） |
| `offscreen` | 超出视口且不可滚动 |
| `occluded` | 文字被其它元素遮挡（含半透明浮层） |
| `overlap` | 可交互控件互相重叠 |
| `hidden-overflow-x` | `no-scrollbar` 容器内容溢出（用户看不到被裁内容） |
| `text-overflow` | 固定宽度 + nowrap 时文字直接画出边框（如时间码数字超框） |
| `ellipsis` / `tiny-font` | 省略号截断 / 字号 < 9px（提示级） |

每个组合都会截图到 `.audit/<width>/<state>.png`，并输出 `.audit/report.json`；
当页面有 `aria-modal` 弹窗时只审计弹窗内部，避免背景遮挡误报。

## 8. 第三轮：轨道多选与轨道头信息重排

用户第二轮反馈：轨道信息排版拥挤、拖选多选难用（鼠标起点在轨道外就失效）。

  批量 M/S、删除、复制、改色、行高、音量/声像相对同步，一次手势一个撤销点。
